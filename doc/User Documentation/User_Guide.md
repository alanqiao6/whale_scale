## ❓ Frequently Asked Questions (FAQ)

### 1. Is the website multi-page?
No, the site is a **single-page application**. You can navigate between sections using tabs, which keeps the interface simple.

### 2. Do I need to click "Update" or "Submit" after editing the sidebar?
Yes. You must click **Update/Submit** after making changes so the server can process and apply the updates.

### 3. Why isn't the ruler tool working?
The **sidebar must be correctly filled out** before the ruler tool becomes available.

### 4. Why aren't my changes saving in the developer version?
In the dev implementation, you **must be logged in** for your data to be saved.
